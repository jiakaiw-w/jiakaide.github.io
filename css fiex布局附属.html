CSS Flex布局零基础入门

2026-01-08
CSS
1892 阅读
45 评论

Flex布局（弹性布局）是CSS3引入的一种强大的布局方式，相比传统的浮动布局，Flex能更简单、灵活地实现元素的对齐、分布和自适应，是前端开发中必备的布局技能。

一、Flex布局核心概念

Flex布局由容器（flex container）和项目（flex item）组成，给父元素设置display: flex后，子元素就会成为Flex项目：

<div class="flex-container">
  <div class="flex-item">项目1</div>
  <div class="flex-item">项目2</div>
  <div class="flex-item">项目3</div>
</div>

<style>
.flex-container {
  display: flex; /* 开启Flex布局 */
  width: 500px;
  height: 300px;
  background-color: #fef7fb;
}
.flex-item {
  width: 100px;
  height: 100px;
  background-color: #ffc0cb;
  margin: 5px;
}
</style>

二、容器的核心属性

1. flex-direction：决定主轴方向

可选值：row（默认，水平从左到右）、row-reverse（水平从右到左）、column（垂直从上到下）、column-reverse（垂直从下到上）

2. justify-content：主轴上的对齐方式

常用值：flex-start（默认，左对齐）、center（居中）、flex-end（右对齐）、space-between（两端对齐）、space-around（均匀分布）

3. align-items：交叉轴上的对齐方式

常用值：stretch（默认，拉伸）、center（居中）、flex-start（顶部对齐）、flex-end（底部对齐）

三、Flex实战案例：居中布局

使用Flex实现元素水平垂直居中，是最常用的场景之一：

<div class="container">
  <div class="box">我是居中的内容</div>
</div>

<style>
.container {
  width: 400px;
  height: 400px;
  background-color: #fcf1f7;
  display: flex;
  justify-content: center; /* 水平居中 */
  align-items: center; /* 垂直居中 */
}
.box {
  width: 200px;
  height: 200px;
  background-color: #e56b8c;
  color: #fff;
  text-align: center;
  line-height: 200px;
}
</style>

四、Flex布局优势

1. 告别浮动和清除浮动的烦恼，代码更简洁；

2. 轻松实现元素的自适应和响应式布局；

3. 对齐方式灵活，能快速实现各种复杂布局；

4. 兼容性好，主流浏览器（IE10+）均支持。

五、总结

Flex布局是前端布局的“利器”，掌握它能极大提升布局效率。建议从基础属性入手，多动手实践，结合实际案例巩固知识点，很快就能熟练运用～
